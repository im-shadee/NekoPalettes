# Changelog

## [1.1.0-rc.2] - 14/09/2026

> Note: This package is still undergoing testing. I'm still not sure when it will be fully ready for a release; there are just so many things tied to it that will only be found and fixed through real usage. If you find any issues, please do report them! :)

### Features
- Migrated from default Unity GUI to UI Toolkit to support multi-selection across swatches.
- Resizable sections allowing the list and preview panes to scale dynamically.
- Interactive zoom support for the live preview with a dedicated reset button.
- Swatch reordering via drag-and-drop.
- Support for custom colors outside the active sprite to build multi-sprite character palettes.
- Global "Reset Colors to Original" functionality.
- Full Undo/Redo support across all editor operations.
- Palette sorting and missing color importing via external 1xN texture assets.
- Persistent split-view configuration across editor reloads.
